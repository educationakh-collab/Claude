# Naruto edit — fully generated

`out/naruto_edit_final.mp4`: a 33-second vertical edit (1080x1920, 30 fps). There is no source footage and no sampled audio. Every frame and every sound is generated by code.

- `music.py` synthesizes a 140 BPM phonk-style track: 808 bass, cowbell arpeggios, claps and hats, taiko, a shakuhachi-style flute, risers and impacts.
- `video.py` draws the visuals procedurally: a ninja silhouette in front of the moon, Sharingan, Rasengan, the Nine-Tails eye and tails in flames, a Rasengan vs Chidori clash, a Rasenshuriken, a sage-mode aura and the Hidden Leaf symbol. Cuts, shake, zoom, glitch effects, chromatic aberration and flashes are all timed to the beat from the shared `common.py` timeline.

```bash
./fetch_fonts.sh                 # Anton + Noto Sans JP (OFL)
python3 music.py out/music.wav
python3 video.py out/naruto_edit_final.mp4 out/music.wav
python3 preview.py sheet.png 5 10 20   # contact sheet of stills
```
